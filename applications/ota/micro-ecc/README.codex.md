# Vendored micro-ecc

This directory contains the verification-only subset of Kenneth MacKay's
micro-ecc at commit `541b3a78026420a3e369c4c9281c396b5e531113`.

Upstream: https://github.com/kmackay/micro-ecc

The original BSD 2-Clause license is preserved in `LICENSE.txt`. The build
enables only `secp256r1` and disables compressed-point support.
